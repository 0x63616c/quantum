Voxelite for macOS (Apple silicon).

1. Download **Voxelite.dmg**, open it and drag Voxelite into Applications.
2. This build is not notarized. The first time, right-click Voxelite in Applications and choose **Open**, then **Open** again. (On macOS 15+, if that is not offered: System Settings → Privacy & Security → "Open Anyway".)
