# Voxelite

A Rust/GPUI voxel editor with a shared document engine and MCP integration.

See the [native editor guide](crates/voxelite-app/README.md) for running the app,
the [domain glossary](GLOSSARY.md) for code terminology and planned architecture
seams, and [ADR 0001](docs/adr/0001-record-architecture-decisions.md) for the
architecture review's recommended order.
