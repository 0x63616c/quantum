# Voxelite is now Quantum


The editor has a new name: **Quantum**. It is still the same local voxel
workspace for people and agents, with portable `.voxl` projects.

Your settings move with you. On startup, the app automatically migrates the
legacy data directory when the new directory does not exist. Settings, palettes,
recent projects and thumbnails stay together. An existing new directory is
preserved; it is never overwritten by the migration.

Existing projects keep their file format, and the app keeps its bundle identity
so automatic updates can find your installation.

[Download Quantum](/download/) or read the
[compatibility decisions](https://github.com/0x63616c/quantum/blob/main/docs/rename-compatibility.md).
