# Local concept fonts

Geist and Geist Mono variable TrueType fonts, copied from the installed Google Fonts distribution. Upstream: [Geist](https://github.com/vercel/geist-font) and [Google Fonts](https://github.com/google/fonts/tree/main/ofl/geist).

Both are distributed under the SIL Open Font License 1.1. Their complete notices are preserved in `OFL-Geist.txt` and `OFL-GeistMono.txt`. The concept builder embeds the local files so each HTML preview works offline. No font service is contacted at runtime. Production GPUI/site/docs will use locally bundled assets and native system fallbacks.
