Each HTML opens directly with embedded CSS, SVG icons, licensed [local Geist fonts](../assets/fonts/README.md), controls and procedural renderer. No server/network assets are required. Base surfaces are pure #000/#fff, metadata is at least 12px, component radii are 6–8px, and shadows are reserved for floating layers. The implementation is an offline HTML design prototype; the production app remains Rust GPUI.

A's interactions:

- File / Edit / View / Tools / Layers / Palette / Agent / Extensions / Help menus, right-aligned shortcuts, separators, nested menus and viewport/layer/palette right-click menus. Menu arrows, Enter, Escape, outside dismissal and focus restoration work. Secondary exports, grid, zoom, mirror options, layer operations, capture refresh and theme live in menus. Tool keys B/E/P/G/U/I and ⌘K/Ctrl+K command search remain available. Checked/disabled items expose actual selection and availability; keyboard traversal skips disabled commands. Tool picker and Extensions both have searchable lists, including Custom → Scatter moss with one Agent badge. Tool selection closes the menu; density/seed settings appear in a separate sidebar section. The tools PNG shows the searchable menu with the custom tool available; runtime execution/registration remains a product requirement.
- The session groups task/agent identity above a prominent live operation, explicit Follow On/Off switch and labeled Pause/Resume. Captures use one large 148px-high canvas with Front/Right/Back segments; clicking the displayed capture selects that camera. Both recent steps show added/removed counts; the latest is expanded by default with Undo step. Coordinates have their own disclosure. Global undo/redo traverses the two canopy edits. Captures preserve their geometry/revision until refreshed; orbit and layer visibility do not silently overwrite them. Pointer orbit, Shift-drag pan, wheel zoom, focused keyboard arrows/Shift-arrows/+/- and Home work.
- The active palette has a compact two-row scrollable swatch area and a switcher. The right-side sheet creates, renames, duplicates and deletes custom palettes; adds/removes/reorders swatches; validates hex edits; and persists custom palettes locally when storage is available. Edits save on Enter or blur; the active palette shows a disabled In use action. Presets show one read-only label and one Duplicate to edit action. Their swatch edit actions are disabled and hidden, and the selected hex is plain text. Applies to new voxels sits beside Use palette. Palette overflow holds duplicate/import/export/delete; swatch overflow holds reorder/remove beside the selected color’s hex field. Switching the brush palette deliberately preserves the cottage's existing colors. Woodland is a 16-color custom working palette drawn from the original art.
- `.hex` import/export uses one six-digit RGB hex value per line, with a final newline. `.gpl` uses `GIMP Palette`, `Name:`, `Columns:`, a comment separator and decimal RGB rows with color labels. Downloads are generated in-browser; imports parse the selected local file and reject invalid/empty/oversized input without replacing a palette. Preset values are verified against the published [PICO-8](https://lospec.com/palette-list/pico-8), [Endesga 32](https://lospec.com/palette-list/endesga-32) and [Sweetie 16](https://lospec.com/palette-list/sweetie-16) lists; Grayscale is exactly 00, 11, …, FF on each channel. No unverified extra presets are included.
- Three subtle comment pins are present in the calm capture. Anchors project from voxel coordinates on every camera redraw and hide when their voxel/layer is absent. Comments opens the sidebar tab; a pin opens its thread, with replies, resolve/reopen and open/resolved/all filters. The canopy thread displays a Canopy agent reply with a small `MCP · comments.reply` note. The selected thread lives only in the sidebar; other threads become compact summaries. Docking guarantees the discussion never overlaps the model at any camera angle or window size. A quiet pin halo replaces the connector and voxel wireframe. Author/message spacing, Resolve in the thread header and an integrated multiline composer keep the conversation readable. Context menus can anchor a new local comment to a picked voxel.
- Share separates Link access from People & agents. Restricted uses only individual grants; an open link grants view, comment or remix access, with the higher of link and individual permissions applying. Remix includes viewing/commenting plus an independent copy, never edits to the original. A single row contains the reserved `.example` URL and Copy link/Copied feedback. Synthetic Artist 01, Designer 02 and Canopy agent entries retain individual permission controls without presence subtitles. Clipboard fallback selects the URL and explains the keyboard copy action. No link is published and no collaboration service is connected.
- The clock or View → History replaces the activity sidebar with history. One scrub track contains human circle/agent diamond ticks; all nine compact fixture rows fit at the default window size, with a bounded scroll region on smaller windows and named collaborator attribution. A persistent Read-only preview banner identifies historical preview and returns to latest. Tool choice, mirror/layer edit commands and undo are disabled during preview, including shortcuts and command search. Closing command search preserves preview mode. Each step rebuilds the viewport from immutable fixture cells: empty, ground, walls, roof, garden, tree structure, canopy and two leaf-detail edits. Step 4 has 1,816 voxels; the complete scene has 2,079. Closing/returning to latest restores the live snapshot. Save preview explicitly saves the displayed historical geometry; Save this state saves the latest state. Named versions restore explicitly, compare actual added/removed cells with solid/dashed overlays, and branch into a local preview lineage. Versions/comments are in-memory fixtures; the branch indicator does not invoke Git.
- Layer eye and lock toggles are always visible. Selected layers, history rows, segmented controls and palette-library entries share a restrained filled selection with a thin border; swatches use a single light outline. Menu focus/hover and open submenu parents use filled highlights, while keyboard focus elsewhere remains distinct.

The cottage is actual projected cube geometry with the original top-left lighting and soft AO. Session events, actor origins, MCP notes and timings are deterministic demonstration data, not evidence of a connected agent or agent-made artwork. Project new/open/save, GLB export, layer creation/rename/duplicate/delete and extension management report preview-only feedback. Painting/placing tools are selectable but do not implement the production editing engine. Read the [product requirements](../REVISIONS.md#product-requirements-2026-10-25) and [roadmap](../../PLAN.md) for the open-core plugin system, real comments/sharing/history/MCP, future Git integration and precision modelling.

```sh
npm ci
npm run build:concepts
npm run render
# During A-only iteration:
npm run render -- --only-a
```

For this revision, the builder writes **A only**. `scripts/lib/concept-a.mjs`, `concept-a.css` and `concept-a-controls.js` own its components and interactions. `scripts/lib/voxel-scene.js` owns the original procedural cottage with A-only history/comment hooks. The previous B/C markup, styles and controls remain in the shared sources and their generated standalone files are preserved.

`npm run render` produces fourteen A images at 1600×1000 CSS pixels, DPR 2 (3200×2000 PNGs). It also runs the existing B/C interaction checks without writing their PNGs. A checks cover offline loading/errors, fonts/minimum text, pure base colors, default/sidebar and floating-layer fit, menus/submenus/context menus, checked and disabled states, keyboard focus, the configured custom tool in Tools/Extensions, palette selection/editing/validation/import/export bytes, immutable captures, undo, camera-projected pins, comment reply/resolve/reopen, share permissions/copy fallback, actual geometry scrubbing, named save/restore/compare/branch and command keyboard behavior. The suite also verifies transparent materials over an ambient underlay, one docked comment thread with no connector/duplicate text, camera-independent separation from the artwork, preview editing locks, exact preview-version geometry, always-visible layer toggles, capture angle switching, searchable menus and a 1100×760 layout with keyboard sidebar resizing and reachable scrolling. Manual image review is recorded separately. This is not production GPUI/MCP, native accessibility or responsive-layout certification.
