# Autumn Workshop

Regenerate the bundled demo from an empty scene, without a renderer or display:

```sh
cargo run --locked -p voxelite-format --example demo-history
cargo run --locked -p voxelite-format --example demo-history -- --check
```

The generator locates `examples/autumn-workshop.voxl` relative to the crate, so it
does not depend on the working directory. It never reads the demo to construct
geometry. `--check` compares the generated bytes with the checked-in asset.

[support/autumn_workshop.rs](support/autumn_workshop.rs) applies 49 real core
transactions: palette and layer setup, earth lifts and turf, meadow and stream
paint, cottage foundations/walls/interior/timber/windows/roof, western oak canopy
regions, garden planting, fence and props, warm glazing, and the original note
and named version. Every step must change the scene and retain the empty initial
state. Paint passes use `Mode::Paint`; carving emits actual air writes. IDs,
coordinate hashing, integer ellipsoid occupancy, and relative times are
deterministic. The logical clock advances one minute per edit; it does not claim
actual authoring dates or durations.

The format crate validates and stores the command recipe. Opening the bundled
scene in the native/web editor or MCP reconstructs the undo and scrub timeline.
An unchanged save retains the recipe; later interactive edits follow the existing
session-local history behavior (see the [format specification](../spec/voxl/1.0/README.md)).

`cargo test -p voxelite-format --locked` pins the original artwork's snapshot and
project hashes from `5afad1f`, including **all** layer voxels, hidden/overlapping
cells, palette slots/order, layer metadata, comments and named versions. It also
checks byte-for-byte regeneration, format round trips, empty initial state,
every undo/redo step, real paint effects, read-only scrubbing, and malformed recipes.
The editor tests exercise the actual bundled-demo loader and unchanged save/reopen.

The existing export command uses the same builder and retains the history:

```sh
cargo run --release --locked -p voxelite-export --example cottage
```

It additionally writes the GLB and reference PNG views under `docs/screenshots`.

To render small AO-off/default comparisons of the pinned workshop, the export
step fixture and the single-voxel format fixture, without modifying the models:

```sh
cargo run --release --locked -p voxelite-export --example cottage -- --ao-comparisons
```

The six 384² PNGs go to `docs/screenshots/ao` (an optional second argument changes
the output directory). See [the comparison notes](../docs/ambient-occlusion.md).
