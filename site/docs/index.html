Documentation

A small world starts with a good first step.

Voxelite is a voxel editor with an MCP interface, a native Rust/GPUI workspace, and a browser build of the same editor. Create with an agent, work by hand, or move between both in a native session.

Getting started ↗Build the app, connect a host, and make your first model.MCP tools ↗The actual server catalog, with parameters and complete schemas.The .voxl format ↗Portable projects, canonical JSON, and the rules on disk.Agent skills ↗Reusable workflows for composition, palettes and visual review.

These docs describe the implementation on the development branch, not a signed public release. Linux builds and Chromium software graphics are verified; macOS release distribution and Safari/Firefox qualification remain pending.

Everything stays local. No account, tracking scripts, cloud relay, or model-provider key is required by Voxelite. Your chosen agent host may have its own requirements.
