This development build uses API voxelite.v1.

A small world starts with a good first step.

Voxelite is a voxel editor with an MCP interface, a native Rust/GPUI workspace, and a browser build of the same editor. Create with an agent, work by hand, or move between both in a native session.

Getting startedInstall the app, connect a host, and make your first model.MCP toolsThe actual server catalog, with parameters and complete schemas.The .voxl formatPortable projects, canonical JSON, and the rules on disk.Agent skillsReusable workflows for composition, palettes and visual review.PluginsBuilt-in features, the core boundary, and writing a plugin.

These docs describe the implementation on the development branch. The native Mac download is Developer ID signed and notarized by Apple, and checks for updates automatically from version 0.3.0. Linux builds and Chromium software graphics are verified; Safari/Firefox qualification remains pending.

Everything stays local. No account, cloud relay, or model-provider key is required by Voxelite, and your projects never leave your machine. This website uses cookie-free Vercel Web Analytics and Speed Insights for anonymous page-view and performance counts; nothing you build is collected. Your chosen agent host may have its own requirements.
