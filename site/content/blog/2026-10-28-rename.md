# Voxelite is now @@product@@

The editor has a new name: **@@product@@**. It is still the same local voxel
workspace for people and agents, with portable `.voxl` projects.

Your settings move with you. On startup, the app automatically migrates the
legacy data directory when the new directory does not exist. Settings, palettes,
recent projects and thumbnails stay together. An existing new directory is
preserved; it is never overwritten by the migration.

Existing projects still open, and new saves use the current product discriminator.
Keep an original copy when sharing with an older application. The app now adopts
the new bundle identity, migrates bundle-keyed macOS state once, and packages a
compatibility copy so installed updaters can find the new build. MCP responses
also use the current API version; clients with exact version validators need an
update before upgrading the app.

[compatibility decisions](@@repo_url@@/blob/main/docs/rename-compatibility.md).
