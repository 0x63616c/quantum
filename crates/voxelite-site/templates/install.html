Install MCP

Install Quantum for Mac in Applications first. The app includes the MCP server. Open your project folder in your host, then choose an install method below. For source builds or a different app location, use the manual configuration with your executable's absolute path.

Cursor

Review and confirm the server in Cursor. The file root is ${{workspaceFolder}}, your open project folder. View mcp.json for manual setup.

Claude Code

Run from your project directory; "$PWD" sets the file root to that directory.

{claude_command}

To make the server available across projects, add --scope user after claude mcp add. Its file root still points to the directory where you ran the command.

Codex

Run from your project directory; "$PWD" sets the file root to that directory.

{codex_command}

Or merge this into ~/.codex/config.toml (or your trusted project's .codex/config.toml). Replace <project dir> with an existing absolute path.

{codex_config}

VS Code

Install in VS Code

Review and confirm the server in VS Code, or run this CLI command. Both use ${{workspaceFolder}} for the file root, resolved by VS Code in your open project.

{vscode_command}

View .vscode/mcp.json for manual setup.

Other

For Claude Desktop, Windsurf and other MCP hosts, merge this entry into the host's MCP settings. Preserve existing servers and replace <project dir> with an existing absolute path.

{generic_config}

Install skills

Install all skills from the repository's skills/ directory with the open Agent Skills CLI. This installs workflow instructions; configure MCP above to give them tools.

{skills_command}

Add --skill <name> for one skill, -g for a global install, or -a claude-code, -a cursor or -a codex to pick an agent. Choose an individual skill.

For a manual install, download the skill folders or use a repository checkout. Copy each skills/<name>/ folder into .cursor/skills/, .claude/skills/, or ~/.codex/skills/. Install, update and removal notes.

What you get

MCP gives your agent voxel editing tools, palettes, real PNG renders, and project save/export. Skills teach it to compose, inspect and refine a model. Each standalone server owns its own session; save .voxl files before disconnecting. To edit the live native canvas, copy the connection configuration from the app.

Verify it works

  1. Restart or reconnect your host and list its MCP tools.
  2. Call voxelite_capabilities_get with {{}}. Expect API voxelite.v1, an epoch and available document IDs.
  3. Confirm the installed skills appear in your host, then ask it to use voxelite-workflow for your first model.
